**@olonjs/core** is the deterministic contract layer of OlonJS. It owns the types, resolution logic, and machine-facing contract emission that make every page a typed JSON contract — and none of the UI. **Zero React at runtime**, one peer dependency (`zod`), two runtime dependencies (`clsx`, `tailwind-merge`), `sideEffects: false`.

## Role in the Stack (ADR-0016)

```
@olonjs/core ──► @olonjs/react   (rendering bindings, dynamic-loads @olonjs/studio)
      │
      └──────► @olonjs/studio   (editor UI — depends ONLY on core)
      │
      └──────► @olonjs/next     (Next.js host binding — server side)
      │
      └──────► @olonjs/sources  (external collection sources — policy never in core)
```

Boundary law, enforced by `scripts/check-package-boundaries.mjs` (`npm run test:boundary`): core never imports react/studio; studio never imports react.

## Install

```bash
npm install @olonjs/core zod
```

`zod@^4.6.0` is a **peer dependency** — the Zod v4 contract is baseline across the whole ecosystem.

## Quick Start

```ts
import { cn, resolveAssetUrl, buildThemeVariableMap } from '@olonjs/core';

// Theme flattening (layer 0 of the CIP theme chain)
const vars = buildThemeVariableMap({ tokens: { colors: { primary: '#0f766e' } } });
// → { '--theme-colors-primary': '#0f766e' }

// Tenant-scoped asset URLs
const url = resolveAssetUrl('/images/hero.png', 'my-tenant');
// → '/assets/my-tenant/images/hero.png'

// The only class-merging utility the ecosystem uses
const cls = cn('bg-[var(--local-bg)]', { 'text-lg': true });
```

## Contracts & Specs

The operative protocol set lives in [`specs/2.0/`](../../specs/2.0/INDEX.md). Core is the normative implementor of:

- **MTRP** — modular type registry (module augmentation, zero core edits)
- **JEB** — engine bootstrap contract (`JsonPagesConfig`, including `WebMcpConfig`)
- **COP** — collection contracts and `$ref` resolution (JSON Pointer, document aliases, circularity guard, `collection:current`)
- **WTP** — WebMCP tool contract emission (`surface: admin|public`, kebab-case validation, built-in collision detection)
- **BSDS** — base schema fragments

**Canonical JSON Schemas** (`https://olon.js.org/schemas/v1/`): Zod is the internal SOT (`src/contract/zod-schemas.ts`, `zod/v3` dialect for the serializer); the published `.schema.json` files are generated by `npm run bump:all` — never hand-edited. See `docs/canonical-schemas-howto.md`.
